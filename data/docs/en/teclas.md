# EntornoLab keyboard shortcuts

This list covers all the keys of the Studio and of Play, and the controller buttons. It is ordered by window: first the Studio, then Play. You can open it at any time in the Studio with Ctrl+F1. In Play, the F1 key says the keys or buttons that work at that moment.

## How the keys are written

- Combinations are written joined with a plus sign: Ctrl+Shift+S means holding down Control and Shift and pressing S.
- Ctrl is the Control key. Shift is the Shift key. Delete is the Delete key (Del). Page Up and Page Down are the Page Up and Page Down keys (PgUp and PgDn).
- The Applications key is the one that opens the context menu. If your keyboard does not have it, use Shift+F10.
- In the Studio menus, each command also has its access key: press Alt, the letter of the menu and the letter of the command.

## Studio: general keys

- F1: opens the user manual.
- Ctrl+F1: opens this list of keyboard shortcuts.
- Ctrl+H: explains what the control that has the focus is for.
- Alt: goes to the menu bar.
- Alt+F4: closes the Studio, or hides it in the notification area if you chose that in Preferences. If there are unsaved changes, it asks first.
- Escape: never closes the main window; it closes dialogs.

## Studio: File menu

- Ctrl+N: new environment.
- Ctrl+O: open an environment.
- Ctrl+S: save.
- Ctrl+Shift+S: save as.

Open example, Recent, Import, Export, Environment properties and Exit have no shortcut: you choose them in the menu with their letter.

## Studio: Edit menu

- Ctrl+Z: undo the last operation. In a text field, it undoes what you typed.
- Ctrl+Y: redo.
- F4: properties of the selected item.
- Ctrl+D: duplicate.
- F2: rename.
- Ctrl+M: move.
- Ctrl+G: rotate.
- Ctrl+R: change size.
- Ctrl+F: find an item by its name.

Delete has no menu shortcut: it is done with the Delete key in the tree or in the list. Set the start point here is chosen in the menu.

## Studio: Insert menu

- Ctrl+Shift+P: level.
- Ctrl+Shift+H: room by size.
- Ctrl+Shift+A: room attached to another.
- Ctrl+Shift+U: door, doorway, window or entrance.
- Ctrl+Shift+O: catalog object.
- Ctrl+Shift+F: sound source.
- Ctrl+Shift+R: landmark.

Polygonal space, Freestanding wall, Stairs, Ramp, Elevator, Surface zone and the Outdoor submenu have no shortcut: you choose them in the menu with their letter.

## Studio: View menu and panes

- F6: next pane (tree, list, properties and map).
- Shift+F6: previous pane.
- Alt+1: environment tree.
- Alt+2: item list.
- Alt+3: properties.
- Alt+4: visual map.
- Alt+5: text description of the environment.
- Alt+Page Up: level above.
- Alt+Page Down: level below.
- Ctrl++: zoom in on the map.
- Ctrl+-: zoom out of the map.
- F8: show the whole map.
- Ctrl+Shift+G: show or hide the grid.
- Ctrl+Tab: switch page (Environment, Description and Activities).

Go to level, Map tool, Snap to grid, Show the visual map and Status bar are chosen in the menu.

## Studio: Tools menu

- F5: check the environment.
- Ctrl+Shift+M: measure between two items.
- F9: walk through the environment with the player.
- Shift+F9: walk through from the selected item.
- Ctrl+,: preferences.

Furnish the space, Stop the walkthrough, Installed add-ons, Online add-on catalog, Create an add-on of your own and the two folders are chosen in the menu.

## Studio: Students and Supervision menus

- Ctrl+L: student records.
- Ctrl+T: saved sessions.
- Ctrl+I: reports.
- Ctrl+U: real-world assessment log.
- F7: live supervision room.

The first time you go into students, sessions, reports or the log, the program asks for the instructor's password, or creates it. After that it does not ask for it again until you close the program or choose «Lock student data».

## Studio: Help menu

User manual (F1), Keyboard shortcuts (Ctrl+F1) and Help for the focused control (Ctrl+H) are in the general keys. What's new, Check for updates, Project website, Report a bug, Create a diagnostic package, Buy me a coffee and About are chosen in the menu.

## Studio: environment tree and item list

- Arrow keys: move through the tree or the list. In the tree, Right Arrow and Left Arrow open and close a branch.
- Left Arrow and Right Arrow in the list: read the name, type, size and position of the item.
- Enter: open the properties of the item.
- Delete: delete the item, with confirmation.
- Applications key or Shift+F10: context menu.

## Studio: properties form

- Tab and Shift+Tab: go to the next or previous field.
- Measurements are typed in meters, with a comma or a period as the decimal point.
- Changes are applied with the «Apply changes» button and can be undone.

## Studio: visual map

Everything you do on the map can also be done from the tree, the list and the menus.

- Up Arrow, Down Arrow, Left Arrow, Right Arrow: move the selected item one grid step.
- Shift+Up Arrow, Shift+Down Arrow, Shift+Left Arrow, Shift+Right Arrow: move it one fine step.
- Space: while it is held down, dragging with the mouse pans the map.
- Escape: cancel the drag or drawing in progress and go back to the selection tool.

With the mouse: clicking selects, dragging moves, the wheel zooms in and out, the middle button pans, double-clicking opens the properties and the right button opens the context menu.

## Studio: insert catalog object

- Ctrl+D: mark or unmark the chosen object as a favorite.

Enter in the «Search» field filters the list immediately, and Enter in the object list chooses the object and moves on to placing it.

## Studio: multi-column lists (standard controls and column reading)

These work in the Studio's multi-column lists: items, problems, furniture proposal, add-ons, activities, rewards, goals, students, connected students, sessions and assessments.

- Up Arrow and Down Arrow: previous and next item.
- Left Arrow and Right Arrow: read the previous and next column of the chosen item.
- Ctrl+1 to Ctrl+9: read that column directly. Ctrl+0 reads the tenth one.
- Ctrl+Shift+Home and Ctrl+Shift+End: read the first and last column.

In the item list of the main window, Ctrl+1 says the name, Ctrl+2 the type, Ctrl+3 the size and Ctrl+4 the position.

## Studio: building dialogs (standard controls)

- Check the environment: Enter in the problem list closes the dialog and takes you to the item. The columns are severity, problem, suggestion and location.
- Find item: Enter in the text field moves to the results list, and Enter in the list takes you to the item.
- Furnish the space: in the proposal, the columns are the object, its size and where it would go. Nothing is placed until you press «Accept the proposal».
- Installed add-ons: Enter in the list shows the details and Delete removes the chosen add-on (only the user's own).
- Online add-on catalog: Enter in the list shows the details, F5 downloads the catalog again and Escape closes, or cancels the download in progress.
- Create an add-on of your own: Ctrl+Tab switches tabs (Details, Objects and Save); in the object list, Enter edits and Delete removes.
- Import from OpenStreetMap: Enter in «Search for a place» searches, and Enter in the list of places moves to the radius.
- Import and export: Escape, while working, cancels the operation.
- Preferences: Ctrl+Tab and Ctrl+Shift+Tab switch tabs.
- Activity form: Ctrl+Tab and Ctrl+Shift+Tab switch tabs. In the reward and goal lists, Enter edits the chosen one and Delete removes it.

## Studio: Activities tab

- Enter: edit the chosen activity.
- Delete: delete the chosen activity, with confirmation.
- Applications key or Shift+F10: menu with all the actions (new, edit, duplicate, delete, move up, move down, check, try now, assign to students and package for the student).

## Studio: live supervision

Commands act on the student chosen in the list of connected students. Inside this window, Ctrl+I and Ctrl+U mean something different from the Students menu.

- Ctrl+P: pause the session, or resume it if it was paused.
- Ctrl+M: send a message, which the game says to the student.
- Ctrl+I: give a hint, with a text or with a beacon for a few seconds.
- Ctrl+R: move the student to a point, chosen by level and space.
- Ctrl+U: change the help they are allowed to use.
- Ctrl+E: add a reward now.
- Ctrl+K: mark this moment with a note, which stays in the recorded session.
- Ctrl+Shift+R: restart the activity, with confirmation.
- Ctrl+Shift+T: end the session, with confirmation.
- F6: say aloud the status of the chosen student, without moving the focus.
- Escape: close the window. If the room is open, it asks whether to close it or leave it open.

## Studio: students, sessions, reports and log

- Escape: close the window.
- Enter, in a list: open or edit the chosen item (the student record, the session details, the assessment).
- Delete, in a list: delete the chosen item. It always asks for confirmation; to delete a student you have to type their alias.
- Applications key or Shift+F10, in the student list: menu with all the actions.
- Space, in the session list of the reports window: check or uncheck the session to compare it.

In «Replay the route», Down Arrow moves through the steps of the route, one by one.

## Studio: all dialogs

- Escape: close or cancel.
- Enter: accept.
- Tab and Shift+Tab: next and previous control.
- Ctrl+H: help for the field that has the focus (in the activity forms, the explanation of each field).

## Help viewer

It opens with F1 (manual), Ctrl+F1 (this list) or from the Help menu.

- Ctrl+F: search for text in the document.
- F3: find the next occurrence.
- Escape: close the viewer.

If the viewer shows the document as text, the «Sections» list takes you to each section: choose one and press Enter. If it shows it as a page, the screen reader's H key jumps from heading to heading.

## Play: walking through an environment with the keyboard

These are the default keys of Play. They can be changed in Options, Keyboard, except Escape, Enter, F1, Ctrl+F12 and the screen keys (F5 and F6, and F4, F7 and F8 in walkthrough mode).

- Up Arrow and Down Arrow: move forward and back.
- Left Arrow and Right Arrow: turn left and right.
- Shift with Left Arrow or Right Arrow: sidestep.
- U: turn around.
- Enter or Space: interact (open a door, pick up a reward, call the elevator, use what is in front of you).
- C: where am I. Pressed twice quickly, it adds the description of the place.
- W, A, S and D: look ahead, look left, look behind and look right.
- Q: around you.
- Tab and Shift+Tab: next nearby thing and previous nearby thing.
- L: discovered places.
- K: compass.
- B: sound cane. If held down, it repeats.
- E: echo.
- O: activity goal.
- P: hint.
- M: confirm. In a test or when locating a place, it says that you have arrived, that you are facing that way or that this is your answer. If there is a question, it opens its answers.
- F2: repeat the last message.
- F3 and Shift+F3: previous message and next message in the history. Also with Page Up and Page Down.
- Control, the left or the right one: silence the speech.
- Home: go back to the start point.
- F1: help, with the list of keys or of the buttons of the connected controller.
- Escape: pause and menu.
- F5: show or hide the map of the level.
- F6: black screen.
- Ctrl+F12: go back to automatic speech (the screen reader or, if there is none, the Windows voice), even if you chose no speech. It works on any Play screen and cannot be changed.

## Play: menus with the keyboard

- Up Arrow and Down Arrow: previous option and next option.
- Left Arrow and Right Arrow: decrease or increase the value of the option.
- Enter or Space: accept.
- Escape or Backspace: back.
- Home and End: first and last option.
- A letter: jumps to the next option that starts with it.
- F1: explanation of the option.
- F2: repeat the last message.
- F3 and Shift+F3: previous and next message in the history.
- Control: silence the speech.
- Ctrl+F12: go back to automatic speech.

When typing text (the alias, the room address or the code): Enter accepts, Escape cancels, Backspace deletes and Up Arrow reads what you have typed.

In «Practice the controls», press any key or button to hear what it does; to exit, press Escape twice in a row.

## Play: instructor walkthrough mode

In addition to the keys for walking through an environment:

- F4: editing menu (place an object, add a reward, mark a point, measure and set the start point). On the controller, the touchpad or the extra button.
- F7: ghost mode, to go through walls and objects.
- F8: jump to any place or level from a list.

## Play: controller in menus

| Button (Xbox / PlayStation) | In a menu |
|---|---|
| Left stick or D-pad up and down | previous and next option |
| D-pad left and right | decrease and increase the value |
| A / Cross | accept |
| B / Circle | back |
| X / Square | repeat |
| Y / Triangle | help |
| LB / L1 | previous message |
| RB / R1 | next message |
| View / Create | help |
| Menu / Options | back |

When typing with the controller, a letter wheel is used: D-pad up and down go through the letters, D-pad right types the chosen one, D-pad left deletes, LB or L1 adds a space and RB or R1 switches between lowercase, uppercase, numbers and symbols.
