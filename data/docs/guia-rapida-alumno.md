# Guía rápida para jugar

## Para empezar

1. Ponte los auriculares: el izquierdo en el oído izquierdo.
2. Abre `EntornoLabJugar.exe`.
3. Elige tu alias en «¿Quién juega?». Si es la primera vez, elige «Soy nuevo: escribir mi alias». Mejor un apodo que tu nombre y apellidos.
4. En el menú, haz primero el «Tutorial».
5. Después, elige «Elegir entorno», el lugar y la actividad.

En los menús: flecha arriba y flecha abajo para moverte, Intro para elegir, Escape para volver y F1 para saber qué hace una opción.

## Las teclas más importantes

| Tecla | Qué hace |
|---|---|
| Flecha arriba y flecha abajo | Avanzar y retroceder |
| Flecha izquierda y flecha derecha | Girar |
| Intro o Espacio | Abrir una puerta, coger un premio, llamar al ascensor |
| C | Dónde estoy |
| W, A, S y D | Mirar delante, a la izquierda, detrás y a la derecha |
| Q | Qué hay alrededor |
| B | Bastón sonoro |
| O | Qué tengo que hacer |
| P | Pista |
| M | Confirmar en un examen: «ya he llegado» o «esta es mi respuesta» |
| F2 | Repetir lo último |
| Inicio | Volver al punto de partida |
| F1 | Ayuda |
| Escape | Pausa |

Con mando: la palanca izquierda anda y gira, A o Equis interactúa, X o Cuadrado dice dónde estás, Y o Triángulo mira delante, el gatillo derecho es el bastón y el botón Menú u Options pausa.

## Consejos

- Chocar no es malo: te dice dónde están las cosas.
- Si te pierdes, pregunta dónde estás (C) o pide una pista (P).
- Antes de jugar, pasa por «Aprender los sonidos» del menú principal.
- Si tu profesor te da un código, elige «Conectar con mi profesor».
- Haz descansos y no subas mucho el volumen.
- Esto es un juego para aprender un lugar. La calle de verdad se cruza siempre con lo que oyes allí y con tu profesor.

## Versión para niños

1. Ponte los cascos.
2. Abre el juego.
3. Elige tu nombre de juego.
4. Juega primero al «Tutorial».
5. Flecha arriba: andas. Flechas a los lados: te giras.
6. Intro: abres puertas y coges premios.
7. C: el juego te dice dónde estás.
8. P: el juego te da una pista.
9. Escape: paras el juego para descansar.
10. Si chocas, no pasa nada: así sabes qué hay.

¡A buscar tesoros!
